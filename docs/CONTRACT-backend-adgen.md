# The backend ↔ adgen handoff contract

**Contract version: 1.1.0**

## This is a pointer, not a copy

The **canonical** contract document lives in the adgen repo:

> `liquidretail_adgen/docs/CONTRACT-backend-adgen.md`

It is deliberately **not** duplicated here. Two copies of a prose document
drift faster and more silently than two copies of code — and a contract
document that disagrees with itself across repos is worse than no document,
because both copies still look authoritative. The whole reason the contract
needed writing down was one bug living in three files across two repos with a
single copy fixed; reproducing that shape for the document itself would be a
poor start.

What is genuinely shared is the **machine-checkable** half, and that is kept
byte-identical by tooling rather than by discipline:

| Artifact | Where | Kept in sync by |
|---|---|---|
| `handoffContract.js` | `services/handoffContract.js` here, `src/services/handoffContract.js` in adgen | `scripts/verifyHandoffContract.js` byte-compares them (check E); adgen's `verifyVendorDrift.js` also tracks the path automatically |
| `verifyHandoffContract.js` | `scripts/` in both repos | Twins, differing only in the require paths and sibling direction — each repo checks its OWN `models/Ad.js` |

## What this repo is responsible for

`scripts/verifyHandoffContract.js` runs in this repo's `npm test`, and
therefore in CI. It asserts that **backend's** live `models/Ad.js` still
declares every contract field with the declared type.

That check exists for a specific hazard on this side. Three contract fields —
`titlingNeeded`, `titlingAttempts`, `titlingResumeState` — are declared in
`models/Ad.js` for **no reason other than to stop Mongoose strict mode
silently dropping adgen's writes to them**. `models/Ad.js` says so in its own
comments. Backend has no titler, so those fields read as unused *here*, which
makes them precisely what a reasonable cleanup deletes. Deleting one would
not throw — the writes would just stop persisting, and the cross-service
handoff would stall with no error anywhere.

## Changing the contract

Do not edit this file to change the contract. The procedure is in the
canonical document (§7) and in the header of `services/handoffContract.js`.
In short: edit `CONTRACT_FIELDS`, regenerate `CONTRACT_DIGEST` with
`node scripts/verifyHandoffContract.js --print-digest`, bump
`HANDOFF_CONTRACT_VERSION`, update the canonical document **and the version
number at the top of this file**, and apply the identical change to the adgen
copy in the same session.

`scripts/verifyHandoffContract.js` fails if the version above and
`HANDOFF_CONTRACT_VERSION` disagree, which is what keeps this pointer from
going stale.
